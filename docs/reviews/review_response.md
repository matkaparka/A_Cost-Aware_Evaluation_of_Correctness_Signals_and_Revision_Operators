- that the Self-Correction Bench datasets exist on HF (`kenhktsui/gsm8k_sc`, `prm800k_sc`, `scli5`);
- the JarvisLabs prices and CLI.

## Changes not requested by the review

- **H1d (new, Tier 1):** self-verdict feedback vs a reliability-matched external verdict in context. It turns "self-reference supplies no evidence" into a test with reliability held fixed, and it mirrors H4a in the parameter arm.
- **Two-host operation:** this laptop has no WSL, so vLLM cannot run here. All GPU work moves to a JarvisLabs VM, recommended A100 80GB ($1.49/h) rather than H100 ($3.49/h): for ≤ 8B bf16 models, A100 time is cheaper per unit of work, and sm_80 has the most mature vLLM support.
- **LF line endings enforced** (`.gitattributes`), because the repo is synced to Linux.
